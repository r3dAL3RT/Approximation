# Аппроксимация функций методом наименьших квадратов

Реализация наименьших квадратов (МНК) для аппроксимации зашумленных данных алгебраическими и ортогональными многочленами.

## Функциональность

- **Генерация данных**: создание зашумленной выборки для целевой функции $f(x) = \sqrt{x+1} - \cos(x)$ на отрезке $[-1, 1]$.
- **Система нормальных уравнений**: решение через матрицу Вандермонда (`numpy.linalg.solve`).
- **Ортогональные многочлены**: построение базиса ортогональных полиномов с использованием трехчленной рекуррентной связи.
- **Оценка точности**: сравнение невязок $S$ для степеней полиномов $n \in [1, 5]$.
- **Визуализация**: построение графиков точек эксперимента и аппроксимирующих кривых (`matplotlib`).

## Зависимости

- `numpy`
- `matplotlib`
